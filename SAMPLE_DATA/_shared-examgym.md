# ส่วนที่แชร์กันทุกไฟล์ Exam_GYM_*

> ExamGym = คลังโจทย์/ฝึกสอบ (product ต่างจากคอร์สเนื้อหา V-Series) — คำอธิบายระบบ 4 อย่างด้านล่างซ้ำเกือบทุกวิชา ถอดมาไว้ที่เดียว ไฟล์รายวิชา (`Exam_GYM_<วิชา>.md`) เก็บเฉพาะสโลแกน Pain Point และส่วนที่ต่างจากเวอร์ชันฐาน

## เหมาะสำหรับ (เหมือนกันทุกวิชา)

น้องระดับชั้น ม.ปลายทุกคน ทั้งน้องที่มีพื้นฐานดีอยู่แล้ว ยิ่งเรียน ยิ่งได้ฝึก และน้องพื้นฐานอ่อน ยิ่งเรียน ยิ่งเก่งขึ้น ถามได้ ตอบได้ เหมือนมีผู้ช่วยส่วนตัว

## 4 ระบบของ ExamGym (เวอร์ชันฐาน)

1. **คลังโจทย์ Unlimited เสมือนจริง** — โจทย์คุณภาพจากทีมวิชาการ อิง Blueprint ล่าสุด ฝึกได้ไม่จำกัด พร้อมระบบจับเวลาจำลองสนามสอบจริง ควิซได้ทั้งปี
2. **Clear Assistance ส่วนตัว** — โจทย์โต้ตอบได้ สงสัยตรงไหนพิมพ์ถามเจาะลึกเพิ่มได้ทันที (หนังสือทั่วไปทำไม่ได้)
3. **Personalized Quiz Feed** — Adaptive โจทย์ที่เหมาะกับระดับเรา ไต่จากง่าย กลาง ยาก แต่ละคนได้โจทย์ไม่เหมือนกัน
4. **Mastery Dashboard** — สรุปสถิติให้เห็นชัดว่าบทไหนแม่นแล้ว บทไหนยังสะบักสะบอม ไปซ่อมได้ถูกจุดก่อนวันสอบจริง
