## สัญลักษณ์ "ที่มา" ในตาราง courses.md

- **ภาพคอร์ส** = อ่านได้จากหน้ารายละเอียดคอร์สจริง (ชื่อ/ชั่วโมง/ราคา ใช้ได้ตรง ๆ)
- **ข้อมูลเดิม** = มีอยู่แล้วใน mock เดิมของ prototype (`MyPathMonthlyPrototype.tsx`)
- **Plan Canvas** = มีแถบคอร์สบน timeline แต่ยังไม่มีหน้าคอร์สจริง — เติมชื่อและช่วงเวลาตามตำแหน่งแถบ
- **ไม่มีข้อมูลสถานะ/ชั่วโมงที่เรียนไปแล้ว** — ทุกคอร์สนับชั่วโมงเต็มจาก 0 ตามที่เจ้าของแผนกำหนด
- **ชั่วโมงของคอร์สกลุ่ม Plan Canvas = ประมาณการ** ตามประเภทคอร์ส (ปรับพื้นฐาน ~18 / เล่มเนื้อหา 12–24 / ตะลุยโจทย์ 18–30) แล้วปรับยอดรวมทั้งแผน (554.5 ชม.) ให้ตรงภาระรวม ~554 ชม. บนหัวตาราง — ส่วนราคายังเว้นเป็น `–`
- วันที่ระดับ "วัน" ของคอร์สที่ไม่มีในภาพ = เดาให้เรียงต่อเนื่องกันในวิชาเดียว (ไม่ซ้อนเวลา) ตามข้อตกลงเดิมของเจ้าของแผน
