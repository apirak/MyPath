## หมายเหตุ

- คอร์สที่มี `ที่มา = ภาพคอร์ส` คือ 5 คอร์สตัวอย่างเดิม — ชื่อ/ชั่วโมง/ราคา อ่านจากหน้าคอร์สจริง; `ข้อมูลเดิม` = มีอยู่แล้วใน mock เดิมของ prototype (`MyPathMonthlyPrototype.tsx`)
- **ไม่มีข้อมูลสถานะ/ชั่วโมงที่เรียนไปแล้ว** — ทุกคอร์สนับชั่วโมงเต็มตั้งแต่ 0 ตามที่เจ้าของแผนกำหนด (ลบคอลัมน์สถานะเดิม เช่น กำลังเรียนอยู่/พิจารณาเรียน ออกแล้ว ถ้าจะใช้ภายหลังดึงกลับจากหน้าคอร์สจริงได้)
- **ชั่วโมงของคอร์สกลุ่ม Plan Canvas = ประมาณการ** ตามประเภทคอร์ส: ปรับพื้นฐาน ~18, เล่มเนื้อหา 12–24 (ตามความยาวแถบในแผน), ตะลุยโจทย์ 18–30 — แล้วปรับยอดรวมให้ตรงภาระรวม ~554 ชม. บนหัวตาราง Plan Canvas
- ช่อง `–` ที่เหลือ (ราคา) = ยังไม่มีข้อมูลจากภาพ — เติมภายหลังได้เลย
- ตัวเลขต่อท้ายรหัส (.1 .2 …) คือลำดับเล่ม/คอร์สในวิชานั้น, `UP` = Upskill, `EX` = ตะลุยโจทย์ก่อนสอบ, `PHY.0` = ปรับพื้นฐานก่อนเข้าเล่ม 1
