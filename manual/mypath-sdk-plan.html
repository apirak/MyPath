My Path SDK: ทีม Learn Anywhere จะใช้งานยังไง และนักเรียนจะเห็นอะไรต่างไป

My Path ที่ตอนนี้เป็น mockup ในแอปเดียว จะถูกแยกเป็น package @learn/mypath ที่ export component เดียวคือ <MyPath>. Learn Anywhere เป็นเจ้าของข้อมูลทั้งหมด ส่งข้อมูลเข้ามาเป็น props และรับการเปลี่ยนแปลงกลับผ่าน callback. หน้าตาเหมือน prototype ทุกจุด ยกเว้น 11 ข้อที่ตั้งใจเปลี่ยน ส่วนใหญ่เป็นเรื่องปุ่ม back และวันเริ่มคอร์ส

ที่มา: docs/mypath-sdk-plan.md, docs/mypath-integration.md, ADR-0001 ถึง 0003 และ GitHub Issues ของ apirak/MyPath

Developer experience · 2

สิ่งที่ทีม host ต้องทำ

  1. ติดตั้ง

    เลือกหนึ่งวิธี ตอนนี้แนะนำ A แต่ยังไม่เปิดใช้จนกว่าจะคุยกับทีม Learn Anywhere

  2. วาง <MyPath> ในแท็บที่ 3

    ให้กล่องที่สูงแน่นอน SDK เติมเต็มและ scroll ข้างในเอง ไม่รู้ว่ามี tab bar

  3. เขียน toMyPathData() จุดเดียว

    แปลง response ของ API เป็น MyPathData. ถ้า SDK เปลี่ยนรูปข้อมูล TypeScript จะเตือนที่ฟังก์ชันนี้ที่เดียว

  4. บันทึกเมื่อ onPlanChange แล้วส่งแผนกลับ

    บันทึกทับได้เลย ไม่ต้อง merge (last write wins) แนะนำอัปเดตจอก่อนรอ server

  5. ทำ endpoint ฝั่ง backend

    catalog, แผนของนักเรียน, วันสอบ, ความคืบหน้า และบันทึกแผน. ความรับผิดชอบ PDPA เรื่องจัดเก็บและความยินยอมผู้ปกครองอยู่ที่ host

import { MyPath } from '@learn/mypath'
import '@learn/mypath/style.css'          // วิธี A เท่านั้น

<div className="h-full">
  <MyPath
    data={toMyPathData(res)}
    onPlanChange={savePlan}
    onBuyCourse={id => navigate(`/shop/${id}`)}
    onStartCourse={id => navigate(`/learn/${id}`)}
  />
</div>
วิธีติดตั้งเหมาะกับสิ่งที่ dev ต้องรู้
A. tarball จาก GitHub Releaseใช้งานจริง (แนะนำ)ได้ไฟล์ build แล้ว ปักเวอร์ชันชัด ขึ้นเวอร์ชันต้องแก้ URL เอง
B. git submoduleไม่อยากพึ่ง registryตั้ง alias + dedupe: ['react','react-dom'], CI ต้อง checkout submodule, ห้าม install ข้างใน vendor
C. file: linkแก้สอง repo พร้อมกันบนเครื่อง dev เท่านั้น ลืม dedupe = Invalid hook call

ไม่ต้องทำ

  • ติดตั้ง react-router, Tailwind หรือ lucide เพื่อ SDK
  • สร้าง StudentCourse ให้ครบทุกคอร์ส
  • เขียน reducer ซ้ำกับ SDK (ได้แผนทั้งก้อนกลับมา)
  • จัดการ loading/error ภายใน My Path
  • แปลงเวลาเอง ถ้าไม่ต้องการยึดเวลา server

ต้องระวัง

  • React และ React DOM ^19
  • CSP ต้องอนุญาต img-src data:
  • ห้ามเขียน style ทับ .mypath-root / mp-*
  • อย่าสลับระหว่างส่งกับไม่ส่ง view ขณะ component ยังอยู่
  • วันที่ทุกตัวเป็น 'YYYY-MM-DD' เวลาไทย, วิชาอ้างด้วย id

โครง repo ระหว่างทำ (#7 – #13)

src/prototype/      ← mockup เดิม แช่แข็ง ไม่แก้        → /prototype/mypath, /prototype/mypath/all
src/host/           ← Learn Anywhere จำลอง             → /, /courses, /mypath/*, /profile
  pages/MyPathTab.tsx    ← <MyPath data=… /> แบบเดียวกับแอปจริง
  fixtures/*.json        ← ข้อมูล mock ที่ host ส่งเข้า SDK
packages/mypath/    ← SDK
  src/index.ts           ← ทางเข้าทางเดียว: <MyPath> + types
  src/plan/              ← buildPlan, progress (copy จาก prototype ไม่เขียนใหม่)
  src/ui/                ← Month, AllTimeline, CourseDetail, StudyCalendar, Progress
  src/mypath.css         ← ทุก class อยู่ใต้ .mypath-root, prefix mp-

host จำลองใช้ SDK แบบเดียวกับแอปจริง ถ้า props ใช้ยาก เราจะรู้ก่อนทีม Learn Anywhere. prototype เปิดเทียบได้ตลอดจนผ่าน #13 แล้วจึงลบ (กู้คืนได้จาก tag mockup-v1)

ช่วงอัปเดตได้เลยต้องแก้ adapter ตาม CHANGELOG

เรื่องที่ยังเปิดอยู่

repo apirak/MyPath เป็น public ใต้บัญชีส่วนตัว ทั้ง source และเอกสารแผน (รวมแผน redesign ของ Phase 2 ที่ยังไม่ออก) จึงเปิดให้ทุกคนเห็น ควรย้ายไป org ของบริษัทแบบ private ก่อนแจกทีม Learn Anywhere. ถ้าย้ายแล้ว วิธี A ต้องเปลี่ยนเป็น registry ที่ใช้ token
  • ช่องทางแจก: #14 ทำแค่ library build และทดสอบด้วย pnpm pack ในเครื่อง ยังไม่มี CI release, tag หรือ publish จนกว่าจะคุยกับทีม Learn Anywhere
  • เริ่มเรียนจากหน้าอื่น: ถ้านักเรียนเริ่มเรียนจากหน้าอื่นของ Learn Anywhere วันเริ่มจะไม่ถูกตรึง host ต้องตั้ง startDate เองถ้าต้องการ
  • ปุ่ม back บน Android: ถ้าพบว่าผู้ใช้ปัดออกจากหน้าคอร์สโดยไม่ตั้งใจบ่อย ค่อยเพิ่ม onOverlayChange (minor)
