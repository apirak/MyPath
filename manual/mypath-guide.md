# คู่มือการใช้งาน `<MyPath>`

> **สถานะ: ร่าง** — เขียนจากโค้ดใน `packages/mypath/src` (branch `sdk-08-study-calendar`) ต้องให้ทีม SDK และ Learn Anywhere ตรวจก่อนส่งต่อ

คู่มือนี้อธิบายว่า component ทำอะไรได้ ใช้อย่างไร และ host ต้องเตรียมข้อมูลอะไรบ้าง

- วิธีติดตั้ง, deep link และการขึ้นเวอร์ชัน อยู่ใน [mypath-integration.md](../docs/mypath-integration.md)
- เหตุผลของแต่ละข้อในสัญญาข้อมูล อยู่ใน [mypath-sdk-plan.md](../docs/mypath-sdk-plan.md#สัญญาข้อมูล)
- ความหมายของศัพท์ (งบปฏิทิน, จังหวะเรียนคอร์ส ฯลฯ) อยู่ใน [GLOSSARY.md](../GLOSSARY.md)

## 1. My Path คืออะไร

แผนเรียนส่วนตัวของนักเรียน TCAS: นักเรียนบอกว่ามีเวลาเรียนเท่าไร เรียนวิชาอะไร แล้ว My Path วางคอร์สให้ต่อกันตามลำดับเล่ม พร้อมวันสอบและ Mock บนปฏิทินเดียว

`<MyPath>` เป็น React component ที่ **แสดงผลอย่างเดียว**:

- host (Learn Anywhere) เป็นเจ้าของข้อมูลทั้งหมดและส่งเข้ามาทาง `data`
- เมื่อนักเรียนแก้แผน SDK ส่งแผนใหม่ทั้งก้อนกลับทาง `onPlanChange` แล้ว host บันทึกเอง
- SDK ไม่ยิง API, ไม่ใช้ localStorage, ไม่ส่ง analytics

## 2. การใช้งานทั่วไป (มุมมองนักเรียน)

| ส่วน                                 | นักเรียนทำอะไรได้                                                                                                                                                                                         | ข้อมูลที่ใช้                                |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| **หน้า Month**                       | ดูคอร์สและสอบของเดือนที่เลือก, เลื่อนทีละเดือน, ดูว่าวันนี้กำลังเรียนอะไร, ดูกลุ่ม "จบแล้วในเดือนนี้"                                                                                                     | `catalog`, `plan`, `events`, `owned`        |
| **หน้า All**                         | ดูแผนทั้งหมดบนแกนเดียว ตั้งแต่ต้นจนสอบ, ลากหัวคอร์สเพื่อเลื่อนวันเริ่ม, ดูกราฟชั่วโมงเรียน/สัปดาห์เทียบกับเวลาที่ลงไว้ในปฏิทินการเรียน (แยกสีส่วนที่เรียนตามแผนกับส่วนที่เกินแผน ชี้ที่แท่งเพื่อดูตัวเลข) | ทั้งหมดข้างบน + `plan.calendar`             |
| **หน้ารายละเอียดคอร์ส**              | ดูแพ็ก ครู บทเรียน ราคา, ตั้งวันเริ่มต้น, ตั้งชั่วโมงต่อสัปดาห์ (1–10), เปิด "ตาม Course ก่อนหน้า", กด "เริ่มเรียน" หรือ "หาซื้อบน OnDemand"                                                              | `courseDetails`, `packs`, `prices`, `owned` |
| **แผงปฏิทินการเรียน** (ปุ่มมุมขวาบน) | ตั้งชั่วโมงเรียนวันธรรมดา / เสาร์-อาทิตย์, เพิ่มช่วงปิดเทอม, ตั้งวันพิเศษรายวัน, เลือกวิชาที่เรียน                                                                                                        | `plan.calendar`, `catalog`                  |

กติกาที่นักเรียนจะเห็น:

- คอร์สในวิชาเดียวกันต่อกันตามลำดับเล่ม เล่มถัดไปเริ่มวันถัดจากเล่มก่อนจบ
- ระยะเวลาคอร์ส = `ชั่วโมงคอร์ส ÷ ชั่วโมงต่อสัปดาห์` ปัดขึ้นเป็นสัปดาห์เต็ม (1 สัปดาห์ = 7 วันปฏิทิน)
- คอร์สแรกของวิชาที่ยังไม่ตั้งวันเริ่มต้น เริ่มที่ "วันนี้" และเลื่อนตามวันนี้ไปเรื่อยๆ จนกว่านักเรียนจะตั้งวัน หรือกด "เริ่มเรียน" (ตรึงวันเริ่มไว้)
- ทุกการแก้มีผลทันที ไม่มีปุ่มบันทึก
- คอร์สและ Mock ที่ยังไม่ซื้อแสดงแบบสีอ่อน พร้อมข้อความ "ยังไม่ได้ซื้อ" สอบจริงสีเข้มเสมอ
- ยังไม่ได้เลือกวิชาที่เรียน (หรือ catalog ว่าง) แสดงหน้าว่าง "วางแผนด้วยตนเอง" ชี้ไปที่ปุ่มปฏิทินการเรียน ไม่พัง

## 3. เริ่มใช้งาน

```tsx
import { useState } from "react";
import { MyPath, type MyPathData, type StudentPlan } from "@learn/mypath";

export function MyPathTab({
  data,
  savePlan,
}: {
  data: MyPathData;
  savePlan: (p: StudentPlan) => void;
}) {
  const [plan, setPlan] = useState(data.plan);
  return (
    <div style={{ height: "100%" }}>
      {" "}
      {/* กล่องที่สูงแน่นอน — SDK เติมเต็มและ scroll ข้างในเอง */}
      <MyPath
        data={{ ...data, plan }} // controlled: ต้องส่งแผนใหม่กลับเข้ามาเสมอ
        onPlanChange={(next) => {
          setPlan(next);
          savePlan(next);
        }}
        onBuyCourse={(courseId) => openShop(courseId)}
        onStartCourse={(courseId) => openPlayer(courseId)}
      />
    </div>
  );
}
```

ตัวอย่างที่ใช้งานจริงใน repo นี้: [src/host/pages/MyPathTab.tsx](../src/host/pages/MyPathTab.tsx) กับข้อมูลตัวอย่าง [src/host/fixtures/mypath.json](../src/host/fixtures/mypath.json)

### Props

| prop                      | บังคับ | ความหมาย                                                                                                          |
| ------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------- |
| `data`                    | ✔      | ข้อมูลทั้งหมด (ดูข้อ 4)                                                                                           |
| `onPlanChange(plan)`      | ✔      | แผนเรียนทั้งก้อนหลังนักเรียนแก้ host ต้องบันทึก **และ** ส่งกลับเข้า `data.plan` ไม่อย่างนั้นหน้าจอกลับเป็นแผนเดิม |
| `onBuyCourse(courseId)`   | ✔      | กด "หาซื้อบน OnDemand" host ตัดสินเองว่าจะพาไปซื้อเล่มเดี่ยวหรือทั้งแพ็ก                                          |
| `onStartCourse(courseId)` | ✔      | กด "เริ่มเรียน" ถ้าคอร์สยังไม่มีวันเริ่มต้น SDK ยิง `onPlanChange` (ตรึงวันเริ่ม) ก่อน                            |
| `today`                   |        | `'YYYY-MM-DD'` ตามเวลาไทย ไม่ส่ง = วันตามเวลาไทยจากนาฬิกาเครื่อง ส่งเมื่อทดสอบหรือต้องการยึดเวลา server           |
| `view`, `onViewChange`    |        | สำหรับ deep link / ปุ่ม back (ดู [mypath-integration.md](../docs/mypath-integration.md#deep-link--ปุ่ม-back))             |

`onPlanChange` ยิงเมื่อไร: slider / สวิตช์ / ช่องวันที่ = ทันที, ลากคอร์สในหน้า All = ครั้งเดียวตอนปล่อย, ปฏิทินการเรียน = เมื่อค่าผ่านการตรวจแล้ว (เช่น ช่วงปิดเทอมไม่ซ้อนกัน)

## 4. ข้อมูลที่ต้องเตรียม

`data: MyPathData` มี 8 ส่วน type เต็มอยู่ที่ [packages/mypath/src/types.ts](../packages/mypath/src/types.ts)

| ส่วน            | คืออะไร                             | ใครน่าจะเป็นเจ้าของ\*              | เปลี่ยนบ่อยแค่ไหน      |
| --------------- | ----------------------------------- | ---------------------------------- | ---------------------- |
| `catalog`       | กลุ่ม → วิชา → คอร์ส                | ทีมคอนเทนต์ / product              | ต่อปีการศึกษา          |
| `plan`          | แผนเรียนที่นักเรียนตั้งไว้          | backend (บันทึกจาก `onPlanChange`) | ทุกครั้งที่นักเรียนแก้ |
| `events`        | วันสอบจริงและ Mock ของนักเรียนคนนี้ | ทีมวิชาการ / backend               | ต่อรอบสอบ              |
| `owned`         | id คอร์สและ Mock ที่ซื้อแล้ว        | ระบบร้านค้า / order                | ทุกครั้งที่ซื้อ        |
| `progress`      | % ความคืบหน้าต่อคอร์ส               | ระบบการเรียน (player)              | ทุกครั้งที่เรียน       |
| `prices`        | ราคาคอร์ส                           | ระบบร้านค้า                        | ตามแคมเปญ              |
| `packs`         | ชื่อแพ็กและครู                      | ทีมคอนเทนต์                        | ต่อปีการศึกษา          |
| `courseDetails` | บทเรียนในเล่ม / สโลแกน ExamGym      | ทีมคอนเทนต์                        | ต่อปีการศึกษา          |

\* สมมติฐาน — ต้องยืนยันเจ้าของข้อมูลจริงกับทีม Learn Anywhere

กติกากลางของทุกส่วน:

- **วันที่** ทุกตัวเป็น `'YYYY-MM-DD'` ตามเวลาไทย ไม่มีเวลาและเขตเวลา ใช้ปี ค.ศ. (SDK แปลงเป็น พ.ศ. ตอนแสดงเอง) วันที่ผิดรูปถือว่าไม่ได้ตั้ง
- **อ้างอิงด้วย id เสมอ** ไม่ใช่ชื่อ เพื่อให้เปลี่ยนชื่อที่แสดงได้โดยแผนเดิมไม่พัง
- **id ที่ไม่รู้จัก** (ไม่มีใน catalog) ไม่แสดง แต่ไม่ทำให้หน้าพัง และ SDK ส่งกลับใน `onPlanChange` ครบ บันทึกทับได้เลย
- **ลำดับใน array = ลำดับที่แสดง** (กลุ่ม, วิชาในกลุ่ม, คอร์สในวิชา)

### 4.1 `catalog` — โครงคอร์ส

```ts
catalog: [
  {
    name: "A-Level", // ชื่อกลุ่ม
    subjects: [
      {
        id: "a_lv_61", // รหัสวิชาของ backend
        name: "คณิต 1",
        color: "#2f6fed", // สีประจำวิชา (hex) ใช้ทั้งแท่ง ป้าย และกราฟ
        courses: [
          // เรียงตามลำดับเล่ม — เล่มแรก = คอร์สแรกของวิชา
          {
            id: "MATH.1",
            name: "Math V-Series เล่ม 1",
            short: "Math เล่ม 1",
            abbr: "เล่ม 1",
            hours: 30,
            cover: "https://…/math1.png",
          },
        ],
      },
    ],
  },
];
```

| ฟิลด์                     | บังคับ | หมายเหตุ                                                                                         |
| ------------------------- | ------ | ------------------------------------------------------------------------------------------------ |
| `name` / `short` / `abbr` | ✔      | ชื่อเต็ม / ชื่อสั้นบนการ์ดและป้ายแทนปก / ชื่อย่อสุดบนแท่งที่แคบ — ต้องมีคนเขียนเอง SDK ไม่ย่อให้ |
| `hours`                   | ✔      | ชั่วโมงเรียนรวมของคอร์ส ใช้คำนวณระยะเวลา ต้องมากกว่า 0                                           |
| `cover`                   |        | URL รูปปก ไม่มี = แสดงป้ายสีวิชาพร้อม `short` แทน                                                |
| วิชาที่ `courses: []`     |        | ได้ แสดงเป็นแถวว่าง (เช่น วิชาที่ยังไม่มีคอร์สขาย)                                               |

### 4.2 `plan` — แผนเรียนของนักเรียน

สิ่งเดียวที่ SDK แก้และส่งกลับ เก็บ **เฉพาะค่าที่นักเรียนตั้งเอง** คอร์สที่ไม่มีใน `courses` ใช้ค่าเริ่มต้น

```ts
plan: {
  calendar: {
    weekdayHours: 1,                                   // ชม./วัน จันทร์–ศุกร์ (0–10, 0 = พัก)
    weekendHours: 3,                                   // ชม./วัน เสาร์–อาทิตย์และวันหยุด
    specialDays: [{ date: '2026-12-12', hours: 5 }],   // ชนะทุกกติกา
    breaks: [{ id: 1, start: '2026-12-21', end: '2027-01-03', hours: 2 }],  // ห้ามซ้อนกัน, start ≤ end
    subjects: ['a_lv_61', 'tgat'],                     // id วิชาที่เรียน — My Path วางแผนเฉพาะวิชาเหล่านี้
  },
  courses: [
    { courseId: 'MATH.1', startDate: '2026-10-01', weeklyHours: 3 },
    { courseId: 'MATH.2', followPrevious: true, followPreviousWeeklyHours: true },
  ],
}
```

| ฟิลด์ใน `courses[]`         | ค่าเริ่มต้นเมื่อไม่มี                          | หมายเหตุ                                             |
| --------------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| `startDate`                 | ไม่มี — เริ่มต่อจากเล่มก่อน (เล่มแรก = วันนี้) | วันเริ่มเร็วที่สุด เป็นอดีตได้ (คอร์สที่เรียนไปแล้ว) |
| `weeklyHours`               | 5                                              | 1–10 ค่านอกช่วงถูกบีบเข้าช่วง                        |
| `followPrevious`            | `false`                                        | ใช้ได้เฉพาะเล่มที่ 2 เป็นต้นไป                       |
| `followPreviousWeeklyHours` | `false`                                        | ใช้ชั่วโมง/สัปดาห์ของเล่มก่อน                        |

**แผนเริ่มต้นของนักเรียนใหม่** (ยังไม่เคยบันทึก) — host ต้องส่งอย่างน้อย:

```ts
{ calendar: { weekdayHours: 1, weekendHours: 3, specialDays: [], breaks: [], subjects: [] }, courses: [] }
```

ค่า `weekdayHours` / `weekendHours` / `subjects` เริ่มต้นเป็นการตัดสินใจของ product — ⚠️ ยังไม่ได้ตกลง ค่าข้างบนเอามาจากข้อมูลตัวอย่าง ถ้า `subjects` ว่าง นักเรียนจะเห็นแผนว่างจนกว่าจะเลือกวิชาในปฏิทินการเรียน

### 4.3 `events` — วันสอบและ Mock

```ts
events: [
  { id: "X1", date: "2028-01-16", label: "สอบ TGAT/TPAT", kind: "exam" }, // สอบจริง — สีเข้มเสมอ
  { id: "M1", date: "2026-12-20", label: "Mock ลองสนาม", kind: "mock" }, // Mock — ซื้อแล้วหรือยังดูจาก owned
];
```

- host กรองให้เหลือเฉพาะรายการที่เกี่ยวกับนักเรียนคนนี้ SDK แสดงทุกรายการที่ได้รับ
- `id` ของ Mock ต้องตรงกับ id สินค้าใน `owned`

### 4.4 `owned`, `progress`, `prices`

```ts
owned: ['MATH.1', 'M1'],                                // id คอร์สและ Mock ที่ซื้อแล้ว (รายการเดียวกัน)
progress: { 'MATH.1': 40 },                             // 0–100, ไม่มี = 0, ใช้เฉพาะคอร์สที่ซื้อแล้ว
prices: { 'MATH.1': { now: 3900, was: 4900 } },         // บาท จำนวนเต็ม, was = ราคาขีดฆ่า (ไม่บังคับ)
```

- `owned` ไม่มีวันหมดอายุในเวอร์ชันนี้
- `progress` host คิด % เอง (ถ่วงน้ำหนักบทหรือวิดีโอเป็นความรู้ของ backend)
- `prices` ต้องเป็นราคาเดียวกับที่ร้านค้าแสดง คอร์สที่ไม่มีราคาไม่แสดงบรรทัดราคา SDK จัดรูปแบบ `฿3,900` เอง

### 4.5 `packs` และ `courseDetails` — หน้ารายละเอียดคอร์ส

```ts
packs: { 'MATH-V': { name: 'Math Admissions TCAS (V-Series)', teacher: 'พี่แท็ป' } },
courseDetails: {
  'MATH.1':  { packId: 'MATH-V', volume: { chapters: ['เซต', 'ตรรกศาสตร์', 'จำนวนจริง'] } },
  'MATH.EX': { examgym: { slogan: '…' } },
}
```

- คอร์สที่ไม่มีใน `courseDetails` แสดงข้อความ "ยังไม่มีรายละเอียดเนื้อหาสำหรับคอร์สนี้"
- แยก `packs` เป็นตารางเพราะหนึ่งแพ็กมีหลายเล่ม ไม่ต้องฝังซ้ำทุกคอร์ส
- มีเฉพาะฟิลด์ที่หน้าจอแสดง ไม่ต้องส่งข้อความการตลาดอื่น

## 5. Checklist เตรียมข้อมูล

**ข้อมูลกลาง (ทำครั้งเดียวต่อปีการศึกษา)**

- [ ] รายการกลุ่มและวิชา พร้อม `id` ที่ตรงกับ backend และสีประจำวิชา
- [ ] คอร์สทุกเล่ม: `id`, ชื่อเต็ม, `short`, `abbr`, ชั่วโมงเรียนรวม, ลำดับเล่มในวิชา
- [ ] รูปปก (URL) — ถ้ามี
- [ ] แพ็ก (ชื่อ, ครู) และบทเรียนของแต่ละเล่ม
- [ ] ปฏิทินสอบจริงและรอบ Mock ของปีนั้น พร้อมกติกาว่านักเรียนกลุ่มไหนเห็นรายการไหน

**ข้อมูลรายนักเรียน (ทุกครั้งที่เปิดแท็บ)**

- [ ] แผนเรียนที่บันทึกล่าสุด หรือแผนเริ่มต้นถ้ายังไม่เคยมี

## 7. ความเป็นส่วนตัว (PDPA)

ข้อมูลนักเรียนทั้งหมดผ่าน host อย่างเดียว SDK ไม่เก็บและไม่ส่งข้อมูลออก การจัดเก็บ สิทธิ์เข้าถึง และการขอความยินยอมจากผู้ปกครอง (นักเรียนส่วนใหญ่เป็นผู้เยาว์) เป็นหน้าที่ของ Learn Anywhere ตาม [DP-001] — `data` ไม่ต้องมีชื่อ อีเมล หรือข้อมูลระบุตัวตนของนักเรียนเลย อย่าใส่เพิ่ม
