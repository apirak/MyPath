# `onPlanChange` ส่งแผนเรียนทั้งก้อน ไม่ส่งเฉพาะส่วนที่เปลี่ยน

ทุกครั้งที่นักเรียนแก้แผนเสร็จ SDK เรียก `onPlanChange(plan)` พร้อม `StudentPlan` ทั้งก้อน (ปฏิทินการเรียน + ค่าของทุกคอร์ส) โดยไม่แนบเหตุผล. host แค่บันทึกแล้วส่งกลับเข้ามา. การลากหัวคอร์สยิงครั้งเดียวตอนปล่อย ไม่ยิงทุกวันที่ลากผ่าน.

## Considered Options

- **ส่งเฉพาะส่วนที่เปลี่ยน (`{ type: 'courseStartDate', courseId, date }`):** ไม่เลือก เพราะการแก้บางอย่างเปลี่ยนหลายฟิลด์พร้อมกัน (ปิด "ตามจังหวะเรียน Course ก่อนหน้า" แล้ว copy ชั่วโมงมาเก็บ, ปิด "ตาม Course ก่อนหน้า" ของคอร์สแรกไม่ได้) host จะต้องเขียน reducer ที่ทำงานเหมือน SDK และสองฝั่งอาจเพี้ยนจากกัน
- **ส่งทั้งก้อน + เหตุผลการเปลี่ยน:** ยังไม่เลือก เพราะยังไม่มีใครใช้ และ SDK ไม่ส่ง analytics ([ADR-0001](0001-mypath-as-react-sdk.md)). เพิ่มเป็น argument ตัวที่สองภายหลังได้โดยไม่ทำให้ host เดิมพัง

## Consequences

- payload ใหญ่กว่าแบบส่งเฉพาะส่วนที่เปลี่ยน แต่แผนของนักเรียนหนึ่งคนมีแค่หลักสิบคอร์ส จึงไม่เป็นปัญหา
- ถ้า host บันทึกช้าและนักเรียนแก้ติดกัน ค่าที่มาทีหลังจะทับค่าก่อนหน้า (last write wins) host ไม่ต้อง merge
