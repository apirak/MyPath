# การซื้อเป็นรายการ id แยกจากแผนเรียน

Host ส่งการซื้อเข้ามาเป็น `data.owned: string[]` ซึ่งเป็นรายการ id ของคอร์สและรอบ Mock ที่นักเรียนถือครองอยู่ (สอบจริงไม่มีการซื้อ) ไม่ใส่เป็นฟิลด์ `owned` ใน `StudentCourse` หรือ `ExamEvent` แบบที่ mockup ทำ. แผนเรียนจึงมีเฉพาะค่าที่นักเรียนแก้ได้ และเป็นค่าเดียวกับที่ SDK ส่งกลับผ่าน `onPlanChange`. การซื้อเปลี่ยนได้ทางเดียวคือการซื้อจริงฝั่ง host.

## Considered Options

- **คง `owned` ไว้ในแผนเหมือน mockup และให้ host ไม่สนค่านี้ใน `onPlanChange`:** ไม่เลือก เพราะแผนที่ค้างอยู่ใน SDK (เช่น ซื้อจากอีกแท็บระหว่างเปิด My Path) จะส่ง `owned: false` กลับไปทับได้ และ host ทุกเจ้าต้องจำว่าต้องตัดฟิลด์นี้ทิ้งเอง
- **รายการสิทธิ์แบบมีรายละเอียด (`{ id, expiresAt }`):** ยังไม่เลือก เพราะยังไม่มี UI ไหนใช้วันหมดอายุ ถ้าต้องใช้ภายหลังค่อยเปลี่ยนเป็น major version

## Consequences

- ใบ 03 (#7) ต้องลบ `owned` ออกจาก type ของ `StudentCourse` และ `ExamEvent` แล้วย้ายค่าใน fixtures ไปไว้ที่ `owned`
- id ของคอร์สและ Mock ต้องไม่ซ้ำกัน เพราะอยู่ในรายการเดียวกัน
