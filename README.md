# Learn Anywhere — As-Is Mockup

Frontend-only React mockup of the current Learn Anywhere website (Figma file "Tung-Kai"),
built as the knowledge base for a later redesign of the My Path page.

- **Stack:** Vite + React 19 + TypeScript + Tailwind CSS 4 + React Router
- **Run:** `npm install && npm run dev`
- **Docs:** `ai-knowledge/` — start with `APP_OVERVIEW.md`
